# セキュ勉

資格試験の学習用サイトです。ヘッダーで資格を切り替えられます（学習記録は資格ごとに分かれます）。

- 情報セキュリティマネジメント試験（SG）：オリジナル35問＋IPA過去問200問
- Claude Certified Architect – Foundations（CCAR-F）：オリジナル68問（[js/ccar.js](js/ccar.js)）

CCAR-Fの問題は，公式の試験ガイド（Exam Guide v1.0）の5分野・タスク項目に沿って作成した非公式の練習問題です。公式の問題やサンプル問題は使っていません。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルドやサーバーは不要です）。

- **ダッシュボード**: 総合正答率、分野ごとの正答率、学習日数、直近14日間の回答数
- **問題演習**: 分野・問題数・出題順（未回答・苦手を優先／ランダム）を選んで解く。キーボードの 1〜4 で解答、Enter で次の問題へ
- **復習**: 前回まちがえた問題の一覧。正解するとリストから外れる
- **設定**: 学習データのバックアップ・復元・リセット

学習データはブラウザ（localStorage）に保存されます。ブラウザのデータを消去すると記録も消えるので、ときどき「設定」からバックアップを保存してください。

## 問題の追加

`js/questions.js` の `QUESTIONS` に、次の形式で追加します。

```js
{
  id: 'sg-tech-008',          // 一意なID。あとから変えると学習履歴との対応が切れる
  exam: 'sg',
  category: 'tech',           // threat / crypto / tech / mgmt / law
  question: '問題文',
  choices: ['ア', 'イ', 'ウ', 'エ'],
  answer: 0,                  // 正解のインデックス（0 = ア）
  explanation: '解説',
},
```

## 過去問

IPA 情報セキュリティマネジメント試験の午前問題（平成30年春期〜令和元年秋期の4回分、200問）を収録しています。

- 問題データ: `js/past/<回>.js`（`addPastExam()` で登録）。正解はIPA公式の解答例と照合済みです。
- 図表: `img/past/<回>-<問番号>.png`（問題冊子から切り出し）
- 解説は本サイトで独自に作成したものです。
- 出典: IPA 情報処理技術者試験 過去問題（https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html）

## 別の資格を追加する

`js/questions.js` の `EXAMS` に資格と分野を追加し、その `exam` を指定した問題を追加します。資格が2つ以上になると、ヘッダーに資格の切り替えメニューが表示されます。
